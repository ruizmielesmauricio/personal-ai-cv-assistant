# Personal AI CV Assistant

## Project Overview

The Personal AI CV Assistant is a Retrieval-Augmented Generation (RAG) application that allows recruiters, hiring managers, and potential employers to interact with my professional experience through a conversational AI interface.

The assistant is trained on a structured knowledge base containing information about my projects, skills, certifications, education, work experience, and technical expertise.

Instead of reading a traditional CV, users can ask questions in natural language and receive contextual answers generated by a Large Language Model (LLM).

Examples include:

- What machine learning projects has Mauricio completed?
- What experience does Mauricio have with SQL?
- Has Mauricio deployed any dashboards?
- What certifications is Mauricio currently pursuing?
- Tell me about Mauricio's NASDAQ forecasting project.

The project was designed to demonstrate practical implementation of Generative AI technologies while also serving as an interactive professional portfolio.

## Project Architecture

The application follows a Retrieval-Augmented Generation (RAG) architecture.

### Knowledge Base

Professional information is stored as structured Markdown documents organised into categories:

- Projects
- Skills
- Work Experience
- Education
- Certifications
- Professional Achievements

Each file acts as a source of truth for a specific topic.

Examples include:

- NASDAQ Machine Learning Project
- Exoplanet Classification Project
- Big Four Dashboard
- Death Dashboard
- Python Skills
- SQL Skills
- Power BI Skills
- DP-600 Certification Plan

---

### Document Processing

The system automatically:

1. Loads all Markdown files.
2. Reads document contents.
3. Splits documents into manageable chunks.
4. Generates embeddings for each chunk.
5. Stores embeddings in a vector database.

This process creates a searchable knowledge base that can be queried using natural language.

---

### Retrieval Layer

When a user submits a question:

1. The question is converted into an embedding.
2. Similarity search is performed against the vector database.
3. The most relevant document chunks are retrieved.
4. Retrieved content is passed to the language model as context.

This ensures responses are grounded in actual portfolio information rather than generated from general knowledge.

---

### Generation Layer

The system uses Google's Gemini model to generate responses.

The language model:

- Receives the user question
- Receives retrieved portfolio context
- Generates a contextual answer
- Restricts responses to information available in the knowledge base

This reduces hallucinations and improves answer accuracy.

## Methodology

### Phase 1 — Knowledge Base Design

A structured folder hierarchy was created to organise information into logical categories.

This included:

- Skills
- Projects
- Education
- Certifications
- Experience

The objective was to make retrieval more accurate and easier to maintain.

---

### Phase 2 — Content Engineering

Each project was documented using consistent templates containing:

- Business objective
- Methodology
- Technologies
- Outcomes
- Skills demonstrated

This improves retrieval quality and answer consistency.

---

### Phase 3 — Embedding Generation

Documents were converted into vector representations that capture semantic meaning.

This allows searches based on intent rather than exact keyword matches.

For example:

Question:

"What machine learning work has Mauricio done?"

Can retrieve:

- NASDAQ Forecasting Project
- Exoplanet Classification Project
- QA Risk Prediction Model

Even if the phrase "machine learning" is not explicitly written.

---

### Phase 4 — RAG Pipeline Development

A retrieval pipeline was developed to:

- Retrieve relevant documents
- Inject context into prompts
- Generate grounded responses

This architecture improves factual accuracy and relevance.

---

### Phase 5 — Deployment

The application was deployed using Streamlit Cloud.

Users can access the assistant directly through a web browser without requiring any local installation.
